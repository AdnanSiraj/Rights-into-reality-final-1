# Files to drop into your repo

1. `Navbar.jsx` → replace `src/components/Navbar.jsx`
2. `public/logo.png` → add to `public/logo.png`
3. `public/favicon.png` → add to `public/favicon.png`

Optional: if you want the browser tab icon updated too, in `index.html` add this line inside `<head>`:
```html
<link rel="icon" type="image/png" href="/favicon.png" />
```

Commit and push — Cloudflare Pages rebuilds automatically.
